# StudyFlow 🎓

เว็บแอปจัดการการเรียนสำหรับนักศึกษา เปิดบนเบราว์เซอร์ได้ทันที ติดตั้งเป็นแอปบนมือถือได้ และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

👉 **ใช้งานได้ที่ <https://bigbosbod-dev.github.io/-/>**

## ฟีเจอร์

| แท็บ | ทำอะไรได้ |
| --- | --- |
| **วันนี้** | สรุปของวันนี้ในหน้าเดียว: คาบเรียน งานที่ต้องรีบทำ (ติ๊กเสร็จได้เลย) สอบที่ใกล้เข้ามา และเวลาอ่านวันนี้ |
| **ตารางเรียน** | บันทึกวิชา (จันทร์–อาทิตย์) ไฮไลต์วันนี้ บอกคาบถัดไป นับถอยหลังวันสอบ และส่งตารางเรียน/งาน/วันสอบเข้าแอปปฏิทิน (.ics) |
| **งาน & โปรเจกต์** | Kanban 3 คอลัมน์ เรียงตามวันส่ง เตือนงานที่เลยกำหนด/ใกล้ส่งด้วยสี และขึ้นตัวเลขบนเมนู |
| **Pomodoro** | โฟกัส / พักสั้น / พักยาว ตั้งเวลาเองได้ มีเสียงและเด้งแจ้งเตือน สถิติวันนี้ / 7 วัน / อ่านติดต่อกันกี่วัน พร้อมกราฟ |
| **คำนวณเกรด** | คำนวณ GPA อัตโนมัติ เก็บประวัติเกรดหลายเทอม คำนวณ GPAX สะสม กราฟเกรดแต่ละเทอม และจำลองเกรดที่ต้องได้ถึงเป้า |

ฟีเจอร์อื่น ๆ
- ☁️ **ซิงก์ข้ามเครื่อง**: ล็อกอินด้วยอีเมล (ไม่ต้องมีรหัสผ่าน) ข้อมูลตรงกันทุกเครื่อง เก็บบน Supabase โดยแต่ละคนเห็นได้เฉพาะข้อมูลของตัวเอง
- 🌙 **โหมดมืด**: สลับได้จากปุ่มบนหัวเว็บ หรือตั้งให้เปลี่ยนตามเครื่อง
- 📱 **ติดตั้งเป็นแอป (PWA)**: มีไอคอนบนหน้าจอโฮม เปิดแบบเต็มจอ และใช้งานออฟไลน์ได้
- 💾 **สำรองข้อมูล**: ส่งออกหรือนำเข้าไฟล์ `.json` ได้จากเมนูตั้งค่า (⚙️) ใช้ย้ายข้อมูลไปเครื่องอื่นได้ด้วย
- ⏰ **แจ้งเตือน**: ก่อนเข้าเรียน และงานที่ต้องส่งวันนี้/พรุ่งนี้ (ขณะเปิดแอป) ตั้งค่าได้ในเมนู ⚙️
- 📅 **ส่งเข้าปฏิทิน**: ปฏิทินของมือถือจะเตือนให้แม้ปิดแอป ถ้าข้อมูลผิดให้ลบปฏิทิน "StudyFlow" แล้วนำเข้าใหม่
- 🎨 **สีประจำวิชา**: ให้สีอัตโนมัติหรือเลือกเอง ใช้สีเดียวกันทั้งตารางเรียน งาน วันสอบ และสถิติ
- 🔗 **แชร์ตารางเรียน**: สร้างลิงก์ให้เพื่อนดูตารางเรียนและวันสอบแบบดูอย่างเดียว (ต้องล็อกอินซิงก์)
- ✏️ แตะคาบเรียน การ์ดงาน หรือวันสอบเพื่อแก้ไข

> ถ้าไม่ล็อกอิน ข้อมูลจะเก็บอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น (`localStorage`) ถ้าล็อกอินซิงก์ ข้อมูลจะถูกเก็บในตาราง `user_data` บน Supabase ด้วย

## ติดตั้งบนมือถือ

- **iPhone / iPad:** เปิดลิงก์ใน Safari แล้วแตะปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดลิงก์ใน Chrome แล้วแตะเมนู ⋮ → **ติดตั้งแอป** หรือกดปุ่ม "ติดตั้ง StudyFlow" ในเมนูตั้งค่าของแอป

## รันในเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

> ถ้าเปิดไฟล์ `index.html` ตรง ๆ จะใช้งานได้ แต่ฟีเจอร์ออฟไลน์และการติดตั้งเป็นแอปต้องเปิดผ่าน `http://` หรือ `https://` เท่านั้น

## แก้หน้าตา (Tailwind CSS)

หน้าตาใช้ Tailwind CSS ที่สร้างไว้ล่วงหน้าเป็นไฟล์ `css/tailwind.css` (เบราว์เซอร์ไม่ต้องประมวลผลเอง แอปจึงเปิดเร็ว)
ถ้าเพิ่มหรือเปลี่ยนคลาส Tailwind ใน `index.html` หรือ `js/*.js` ให้สร้างไฟล์ CSS ใหม่ก่อน commit:

```bash
npm install        # ครั้งแรกครั้งเดียว
npm run build:css  # หรือ npm run watch:css ระหว่างแก้
```

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ
css/tailwind.src.css  ต้นฉบับ Tailwind (คลาสที่ใช้ซ้ำ)
css/tailwind.css      CSS ที่สร้างแล้ว (ห้ามแก้ตรง ๆ)
css/style.css         ฟอนต์และสไตล์เพิ่มเติม (สีประจำวิชา ฯลฯ)
js/app.js             โค้ดการทำงานหลัก
js/sync.js            ล็อกอินและซิงก์ข้อมูลกับ Supabase
sw.js                 service worker (ทำให้ใช้ออฟไลน์ได้)
manifest.webmanifest  ข้อมูลสำหรับติดตั้งเป็นแอป
icons/                ไอคอนแอป
```

เมื่อแก้ไฟล์ของแอป ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `studyflow-v3`) เพื่อให้เครื่องที่ติดตั้งแอปไว้ได้เวอร์ชันใหม่
