# StudyFlow 🎓

เว็บแอปจัดการการเรียนสำหรับนักศึกษา ใช้งานบนเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์

| แท็บ | ทำอะไรได้ |
| --- | --- |
| **ตารางเรียน** | บันทึกวิชา วัน เวลา และห้องเรียน (จันทร์–ศุกร์) |
| **งาน & โปรเจกต์** | Kanban 3 คอลัมน์ (ยังไม่เริ่ม / กำลังทำ / เสร็จแล้ว) พร้อมกำหนดส่ง |
| **จับเวลา Pomodoro** | จับเวลาโฟกัส 25 นาที และเก็บสถิติเวลาอ่านของแต่ละวิชา |
| **คำนวณเกรด (GPA)** | คำนวณ GPA เทอมนี้ และจำลองว่าต้องได้เกรดเท่าไหร่ถึงจะถึง GPAX เป้าหมาย |

ข้อมูลถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ จึงอยู่เฉพาะในเครื่องและเบราว์เซอร์ที่ใช้งาน

## วิธีใช้งาน

- **เปิดในเครื่อง:** ดับเบิลคลิก `index.html` หรือรัน `python3 -m http.server` แล้วเปิด <http://localhost:8000>
- **ออนไลน์ด้วย GitHub Pages:** ไปที่ *Settings → Pages* เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save

## โครงสร้างไฟล์

```
index.html     หน้าเว็บ (HTML + Tailwind classes)
css/style.css  ฟอนต์และสไตล์เพิ่มเติม
js/app.js      โค้ดการทำงานทั้งหมด
```
